# Greenden: Plant Shop Website (Tailwind CSS)

A responsive website for a plant shop called **Greenden** ("Plants for your interior"), built to practise Tailwind CSS.

## Pages and sections

- **Home** (`index.html`): hero, about us, benefits (large assortment, free and fast shipping, 24/7 support) and a product grid
- **Contact** (`contact.html`): contact page

## Tech Stack

- HTML5
- [Tailwind CSS 2.2](https://v2.tailwindcss.com/) (loaded from a CDN)
- [Font Awesome 6](https://fontawesome.com/) icons

## Run locally

No build step is needed.

```bash
git clone https://github.com/BALASUBRAMANIYAN-S/Project_of_TailwindBased_GreendenWebsite.git
cd Project_of_TailwindBased_GreendenWebsite
```

Open `index.html` in a browser. An internet connection is needed for the CDN styles and icons.
